# Technology Stack: FixMySpot

## Backend Runtime & Database
- **Runtime:** Python 3.12+
- **Framework:** FastAPI (Asynchronous ASGI)
- **Database:** MongoDB Atlas via Motor (`motor.motor_asyncio.AsyncIOMotorClient`)
- **Data Validation & Schemas:** Pydantic v2
- **Authentication & Cryptography:** PyJWT, Bcrypt
- **Audio Intelligence:** OpenAI Whisper Speech-to-Text

## Frontend Client Architecture
- **Framework:** React 19, React Router v7
- **Bundler / Build:** Craco / Webpack 5
- **Styling & Components:** Tailwind CSS, Radix UI headless primitives
- **Maps & Geolocation:** Leaflet, React-Leaflet
- **Data Visualization & Analytics:** Recharts, jsPDF & jsPDF-AutoTable
- **Internationalization:** i18next (English, Hindi, Marathi)
- **Icons:** Phosphor Icons (`@phosphor-icons/react`)
